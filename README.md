# Sistema de Mantenimiento de Equipos (SMEAN)

## Descripción
Proyecto informático orientado a la gestión y mantenimiento de equipos.

## Objetivo
Facilitar el registro de equipos, el control de mantenimientos, la consulta del historial y la generación de reportes.

## Tecnologías
- HTML
- CSS
- JavaScript
- Git
- GitHub
- PHP

## Estructura
- `src/`: código fuente.
- `docs/`: documentación y matriz del proyecto.
- `assets/`: imágenes y recursos.
- `tests/`: pruebas del sistema.
